CoolCat 桌面小猫 —— 安装说明
================================

1. 安装
   解压后把 CoolCat.app 拖进「应用程序」文件夹，再从「应用程序」里打开。
   （不要直接在「下载」里运行：macOS 会把它放进临时目录，Claude Code 联动会连不上。）

2. 第一次打开（这个包没有做 Apple 公证）
   双击会提示"无法验证开发者"，点「完成」关掉提示，然后：
   打开「系统设置 → 隐私与安全性」，滑到最下面，找到 CoolCat 那一行点「仍要打开」，再确认一次。
   之后就能正常双击打开了。
   也可以在终端执行一次：
       xattr -dr com.apple.quarantine /Applications/CoolCat.app

3. 两个系统授权（都只在本机使用，不录制、不上传）
   · 输入监控：让小猫跟着你打字、按快捷键做反应。
     点小猫底下的提示条，或去「系统设置 → 隐私与安全性 → 输入监控」勾选 CoolCat，然后右键小猫选「重启 CoolCat」。
   · 录制系统音频：第一次用网易云 / Apple Music / Spotify 等放歌时会弹出，选「允许」。
     小猫身后的频谱墙和跳舞才会跟着真实的歌走（需要 macOS 14.2 或更新；更早的系统用模拟节拍）。

4. Claude Code 联动（可选）
   右键小猫 →「Claude Code 联动 🤖」→「连接 Claude Code」。
   会在你的 ~/.claude/settings.json 里加几个 hook（原文件自动备份，其他配置不动）。
   之后新开的 Claude Code 会话里，小猫会显示每个会话在干什么、等你批准时挥爪提醒、完成时撒彩带。
   不想要了：同一个菜单里点「断开 Claude Code」。

5. 好玩的东西
   · 听歌：戴耳机、身后频谱墙跟着鼓点跳；不打字时跳舞（舒缓的歌跳慢舞）。
   · 开会：开麦戴耳麦、打字太吵会"嘘"你、开摄像头先洗把脸。
   · 打字：狂按退格冒汗、⌘S 盖章、截图比耶、手速破纪录戴皇冠。
   · 空闲：打哈欠、伸懒腰、踩奶、慢眨眼……
   所有功能都能在右键菜单里单独关掉。
